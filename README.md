# Vendor Performance Analysis Dashboard

## Project Overview
This project focuses on analyzing vendor performance, sales, purchases, profitability, and inventory efficiency using Python, MySQL, and Power BI. An interactive dashboard was developed to identify top-performing vendors, evaluate brand performance, and highlight areas requiring improvement.

## Objectives
- Analyze vendor-wise sales and purchase performance.
- Evaluate gross profit and profit margins.
- Identify top-performing vendors and brands.
- Analyze low-performing vendors and brands.
- Calculate unsold inventory capital.

## Tools & Technologies
- **Python:** Data cleaning, data processing, and analysis.
- **MySQL:** Data storage and querying.
- **Power BI:** Interactive dashboard and data visualization.
- **DAX:** Measures and calculated columns for business KPIs.

## Dashboard Features
- Total Sales
- Total Purchase
- Gross Profit
- Profit Margin
- Unsold Capital
- Purchase Contribution by Vendor
- Top Vendors by Sales
- Top Brands by Sales
- Low Performing Vendors
- Low Performing Brands

## Key Insights
- Identified vendors contributing the highest purchase value.
- Compared sales performance across vendors and brands.
- Highlighted low-performing vendors and brands.
- Evaluated profitability and unsold inventory to support business decisions.

## Conclusion
This project demonstrates the use of Python, MySQL, and Power BI to transform vendor data into meaningful business insights through data analysis and interactive visualization.
